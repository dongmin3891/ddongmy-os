# Architecture Decision Records

이 디렉터리는 서비스의 제약, 검토한 대안과 기술 선택의 결과를 기록한다. 구현 과정과
시행착오는 Development Log에 남기고, ADR에는 다시 같은 결정을 내려야 할 때 필요한
근거만 유지한다.

## 작성 규칙

- 이미 끝난 의사결정을 나중에 정리한 경우 상태에 `회고 기록`이라고 표시한다.
- 문제, 제약, 검토한 대안, 결정, 감수한 비용과 검증 결과를 기록한다.
- 측정하지 않은 비용이나 효과는 수치로 추정하지 않고 남은 위험으로 구분한다.
- 결정이 바뀌면 기존 문서를 삭제하지 않고 새 ADR에서 대체 관계를 연결한다.
